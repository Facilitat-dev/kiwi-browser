# Canopy brand kit

Privacy-centric browser for Android and Linux. In-app palette: **Canopy purple / AMOLED** (`identity.toml`).

## Start here

1. Agents: read `AGENT_BRAND.md`, then `tokens/tokens.json`.
2. Humans: open `Canopy_Brand_Kit.pptx`.
3. Engineers: import `tokens/tokens.css`.
